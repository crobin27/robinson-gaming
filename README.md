# robinsongaming.com

Personal site / portfolio for Cole Robinson, plus the privacy policy and `app-ads.txt` for Robinson Gaming's published mobile apps.

## Stack

Astro 6 · React 18 · Tailwind 4 · TypeScript · Vercel · Cloudinary (photo gallery)

## Local dev

```bash
pnpm install
pnpm dev
```

Other scripts: `pnpm build`, `pnpm typecheck`, `pnpm lint:all`, `pnpm format`.

## Env

```
PUBLIC_CLOUDINARY_CLOUD_NAME=...
```

## Deploy

Auto-deploys to Vercel on push. `dev` → preview, `prod` → production.
